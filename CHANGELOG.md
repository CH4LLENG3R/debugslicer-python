# Change Log

All notable changes to the "debugslicer-python" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0]

First release.

- View NumPy arrays, PyTorch tensors and Pillow images from the debugger's Variables pane, each in its own tab.
- 2D images in mono, gray + alpha, RGB and RGBA, and 3D volumes in three linked views.
- Per-dimension roles, including constants for extra dimensions.
- Colormaps: presets, automatic unique colours for labels, and your own saved maps.
- Position and value readout, and screenshots to the clipboard.
